Overview

A 3D game built on a custom engine, with C# gameplay scripting powered by an embedded Mono runtime.

I worked as a scripting and gameplay programmer on Cappy The Bara while the team built its 3D engine from scratch in C++ and OpenGL. My focus was connecting the engine to a practical scripting workflow and using it to create game-ready behaviours.

What I did

  • Integrated the Mono scripting library into the custom engine
  • Enabled C# scripting for gameplay development
  • Wrote AI behaviours for in-game opponents and boss fights

Outcome

The Mono integration gave the custom engine a C# gameplay layer for faster iteration on enemies, bosses, and other scripted behaviours.
