Overview

A 2D puzzle adventure about piloting a submarine through a twisted underwater cavern using sonar as your guide.

SONAR was our team’s first game project, written in C with an OpenGL wrapper. As technical and design lead, I shaped the engine and gameplay flow around the sonar mechanic.

What I did

  • Designed the game engine architecture
  • Designed the gameplay flow
  • Implemented the ray-cast physics behind the core sonar mechanic

Outcome

A focused puzzle-adventure prototype whose navigation, atmosphere, and level-reading all emerge from one core mechanic.
