# Liu Hanqing — Game Portfolio

Static GitHub Pages edition of the Black Signal portfolio.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will publish the site at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Editing

- The homepage is `index.html`.
- Shared styling is in `assets/styles.css`.
- Each project detail page has its own folder under `projects/`.
- The three current trailers are loaded from Wix-hosted video URLs.
- Cappy The Bara currently displays a deliberate trailer placeholder.

No build step is required.
